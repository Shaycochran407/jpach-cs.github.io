Private functions — src/code.c

These are static — internal helpers, not visible outside code.c. Implement them first — public functions depend on them.

Function Description
_nullify Set pointer to NULL via double pointer
_findFirst Return the first node (head)
_findLast Walk to the last node and return it
_findValue Walk and return first node matching value

Public functions — src/code.c

Function Description
initNode Initialize an existing node — set value, clear nextPtr
createNode Allocate a new node on the heap via malloc
destroyNode Free a heap node and set pointer to NULL
destroyList Free all nodes in the list one by one
addFirst Insert node at the front of the list
addLast Insert node at the end of the list
detachFirst Remove and return the first node — no free
detachLast Remove and return the last node — no free
detachValue Find, remove and return a node by value — no free
deleteFirst Remove and free the first node
deleteLast Remove and free the last node
deleteValue Find, remove and free a node by value
printList Print all values one per line
listLength Return the number of nodes in the list

detach = remove from list, caller decides memory. delete = remove from list AND free — heap only. delete is always: detach + destroyNode.
