Points: 10

Instructions

  1. Fork the repository on GitHub: https://github.com/jpach-cs/232-ass03-template
  2. Clone your forked repository to your local machine.
  3. Open src/code.c and src/tests.c.
  4. Uncomment the author block at the top of src/code.c and fill in your name:

  1. Work through each function in two parts:

Part 1 — src/code.c

  • Read the description and hint for each function.
  • Implement the function body.
  • Do not modify function signatures.

Part 2 — src/tests.c

  • Read the description for each test function.
  • Implement the test body using TEST_ASSERT_TRUE_MESSAGE.
  • Use only stack variables — no malloc.
  • Do not modify function names or signatures.
  1. When all local tests pass — commit and push to your repository.
  2. Go to the Actions tab on GitHub and verify the CI results.

Functions to implement — src/code.c

Function Description
swap Swap values of two integers via pointers
find_last_char Return pointer to last character before \0
link_three Connect three nodes: a -> b -> c -> NULL
remove_middle Reconnect a -> c, disconnect b
remove_last Set b->nextPtr = NULL
remove_first Set a->nextPtr = NULL
swap_ptrs Swap two pointers using double pointers
nullify Set pointer to NULL via double pointer
assign_bytes Assign bytes 1..8 via cast pointer
sum_chain Return sum of all values in chain

Tests to implement — src/tests.c

Test function What to verify
test_swap_basic Two different values are exchanged
test_swap_equal Equal values remain unchanged
test_find_last_basic Correct pointer to last character
test_find_last_single Single character string
test_find_last_empty Empty string returns NULL
test_link_three_chain All three pointers correctly set

Rules

  • Work on stack only — no malloc, no free
  • Do not modify function signatures in code.c or tests.c
  • Every TEST_ASSERT_TRUE_MESSAGE must include a meaningful message
  • CI runs your tests.c together with instructor tests — both must pass
